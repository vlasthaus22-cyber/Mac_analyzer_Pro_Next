# MAC Analyzer Pro Next v2.3.4

Стабильный полный выпуск: автономное приложение, Windows host, исходный код, документация, справочные данные и инструкции.

## Исправления

- В поиске Inventory прокрутка виртуальной таблицы подключена к реальному контейнеру результатов. На страницах более 50 строк теперь доступны все строки, включая записи после первых 20.
- Столбцы «Адрес» и «Физический адрес» отображаются раздельно. Физический адрес виден по умолчанию и добавлен в таблицу результатов однофайлового анализа.
- Сохранённые стандартные настройки столбцов обновляются автоматически; пользовательские подписи и явное скрытие полей сохраняются.

## Проверки и комплект

- Полный `pnpm check`, release readiness, сборка Windows host и проверка ZIP.
- Полный Chrome browser-smoke на автономном HTML с отдельным временным профилем и disposable IndexedDB.
- Полный ZIP содержит HTML, Windows host, исходники, документацию, справочные данные, тесты и инструкции; к нему приложен SHA-256 sidecar.
