# MAC Analyzer Pro Next v2.3.19

- **Архивы по периодам.** Укажите даты в разделе «База, справочники и экспорт» и нажмите «Сохранить архив файлом». После успешной записи `.madb.json` архивированные снимки скрываются из аналитики и хронологии. Новые объединения сразу доступны в аналитике.
- **Просмотр выбранных архивов.** «Подтянуть старые архивы» подключает несколько файлов за раз. Аналитика объединяет их с текущими снимками по стабильным ID. Рабочая база и активный снимок сохраняются.
- **MAC вне последних пяти Main.** Отчёт показывает устройства, встречавшиеся в более раннем Main и отсутствующие во всех пяти последних доступных снимках. Для каждого устройства доступны последний известный IP, адрес, помещение, модель и переход к хронологии.
- **SmartRoom и аналитика.** Программа автоматически выбирает явно подписанную колонку «SmartRoom ID локации». При повторном сравнении готовый индекс используется сразу, а ход расчёта виден на странице.

Полный ZIP содержит автономный HTML, Windows-компонент, исходники, справочники и документацию. Для файлов сборки приложены контрольные суммы SHA-256.
