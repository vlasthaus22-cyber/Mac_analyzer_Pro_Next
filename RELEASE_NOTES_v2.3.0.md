# MAC Analyzer Pro Next v2.3.0

Полный стабильный выпуск browser-first версии MAC Analyzer Pro Next. Исходная функциональная матрица проверена: **188/188 требований полностью подтверждены**, открытых обязательных пунктов нет.

## Изменения

- Компактнее отображаются графики и KPI аналитики, чтобы быстрее видеть основные результаты без лишней прокрутки.
- Настройки переноса базы, OUI, автоподбора производителя и модели, внешнего API, исторического обогащения и правил IP-коммутатора сворачиваются и открываются по запросу.
- Таблица IP-коммутатор → физический адрес больше не разрастается из-за длинных значений; полный текст доступен по наведению.
- Руководство подробно объясняет, как хранится браузерная IndexedDB, где искать старые SQLite-базы, как экспортировать и восстанавливать `.madb.json`, а также как импортировать `mac_analyzer_settings.json`.

## Проверки

- `pnpm check` завершился успешно: синтаксис, ESLint, portable HTML/worker, Windows host и runtime, полный набор Node-тестов, Python **199/199** и верификация полного ZIP.
- `pnpm check:release-readiness` прошёл: **188/188 требований (100%)**, code/test coverage **188/188 (100%)**.
- Полный browser smoke завершился `ok: true` в изолированном headless Chrome с disposable IndexedDB. Проверены импорт Main/SmartRoom/DDIO, повторный пакетный запуск, сравнения двух и трёх файлов, Dashboard на 5 000 устройств, фильтры и аналитика, переносимые архивы, экспорты и восстановление после перезапуска.

ZIP содержит автономный HTML, исходный код, документацию, migrations/reference data и инструкции; пользовательские базы данных в пакет не входят.

Для переноса пользовательских данных между браузерными профилями используйте portable database archive. Optional Windows host нужен для локальных SQLite-возможностей и не синхронизирует IndexedDB автоматически.

## Артефакты

В релиз приложены автономный HTML, Windows host и полный ZIP с исходниками. Отдельные SHA-256 sidecar-файлы опубликованы рядом с каждым артефактом.
