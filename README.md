# MAC Analyzer Pro Next

Новая независимая реализация MAC Analyzer Pro. Приложение написано как
browser-first SPA на HTML, CSS и ES-модулях JavaScript. Для основной работы не
нужны Python, сервер, права администратора или установка программы.

## Запуск

Для автономного запуска откройте собранный `dist/MAC-Analyzer-Pro-Next.html` в
актуальном Chrome или Edge. В Windows его также открывает `START_MAC_ANALYZER.cmd`;
команда запускает файл в браузере по умолчанию и не поднимает backend или сервер.
Если автономный файл ещё не собран, выполните `pnpm build`. Исходный модульный
`index.html` запускайте через любой статический HTTP-сервер:

```powershell
python -m http.server 8080
```

После этого откройте `http://127.0.0.1:8080`.

Дополнительно можно запустить standalone HTML через отдельный локальный
loopback-host командой `START_MAC_ANALYZER_SERVER.cmd` (требуется Python 3).
Launcher закрепляет выбранный порт в `%LOCALAPPDATA%\MAC Analyzer Pro Next`,
проверяет `/api/health` и открывает браузер только после успешного ответа.
Этот host служит только локальной оболочкой: база остаётся в IndexedDB профиля
браузера, а SQLite API и общая база пока не предоставляются. Для запуска без
Python используйте обычный `START_MAC_ANALYZER.cmd`.

Автономный файл создаётся командой `pnpm build`; OUI-справочник и весь код
встраиваются внутрь HTML.

Полный исходный пакет с автономным HTML, кодом, тестами, документацией,
лицензиями и reference-данными создаётся командой `pnpm package:release`.
Команда пишет ZIP и его SHA-256 в `dist/`; встроенный `SHA256SUMS.txt`
позволяет проверить каждый файл архива. Пользовательские базы и логи в пакет
не включаются.

## Основной сценарий

Отдельный файл можно проверить через «Анализ одного файла»: колонкам можно
назначить поля вручную, результат группируется по сильной идентичности и
экспортируется в CSV/JSON. Анализ сохраняет отдельную локальную историю с
поиском, повторным открытием и удалением, не создавая Final и не меняя Inventory.
Для попарной проверки добавьте до десяти CSV/TSV/TXT/XLS/XLSX/XLSM файлов, задайте
mapping каждого и выберите поля сравнения; общий CSV содержит все направленные
пары.

1. Добавьте основной файл, файл SmartRoom и при необходимости DDIO.
2. Проверьте автоматически найденные колонки.
3. Выберите стратегию количества устройств.
4. Запустите обогащение.
5. Итоговый Final атомарно сохранится в IndexedDB.
6. Используйте поиск, аналитику, историю MAC и хронологию помещений.

В аналитике можно открыть временную статистику за 30, 90 или 365 дней с
группировкой по дням, неделям или месяцам и выгрузить таблицу в CSV.

Поддерживаются CSV, TSV, TXT, JSON, XLS, XLSX и XLSM. Legacy XLS читается локальным
BIFF-парсером в автономном HTML; его размер ограничен 16 MiB из-за полного
декодирования книги в память. DDIO использует независимые пары
MAC/IP резервации и аренды. Значение IP из DDIO заполняет только пустой IP
устройства при точном совпадении MAC и не связано с IP коммутатора.

Миграция функциональности из эталонного приложения продолжается. Текущие
реализация, тесты и оставшиеся различия перечислены в `PARITY_REGISTRY.md`;
матрица не считается завершённой до browser smoke всех основных сценариев.

## Хранение

- Final-снимки записываются порциями в IndexedDB.
- Inventory хранит все когда-либо известные устройства отдельно от текущего Final.
- Неудачное обогащение не заменяет последний успешный Final.
- Полный архив Next можно выгрузить в `.madb.json` и импортировать обратно; для обмена с MAC Analyzer Pro предусмотрен потоковый `.macarchive.json` v2.
- Настройки интерфейса не являются источником бизнес-данных.

Рабочая база Next находится в IndexedDB текущего профиля Chrome/Edge, а не в
отдельном файле рядом с HTML. Для переноса нажмите «Выгрузить архив Next» в
разделе «База, справочники и экспорт», сохраните скачанный
`mac-analyzer-next-ГГГГ-ММ-ДД.madb.json` в резервную папку/на USB и на другом
компьютере выберите его через «Загрузить архив». В типовой Windows-Portable
поставке SQLite-история старой PyQt-версии находится в `data/legacy/`:
`mac_history.db`, `vendor_model_history.db` и, если есть, `mac_analyzer_stats.db`.
При заданной `MAC_ANALYZER_DATA_DIR` ищите файлы в `<каталог>/legacy/`. В
самостоятельном PyQt-запуске `mac_history.db` и `vendor_model_history.db`
открываются относительно рабочей папки процесса; проверьте `Start in` ярлыка
или папку запуска. В Next импортируйте каждый нужный файл отдельно через
«Импортировать SQLite» в инженерном режиме.
Подробные шаги и путь к отдельной таблице vendor/model описаны в руководстве
внутри приложения и в [инструкции по хранению](docs/DATA_STORAGE.md).
