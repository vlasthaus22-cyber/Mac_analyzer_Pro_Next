# MAC Analyzer Pro Next v2.3.12

- Исправлен автоподбор SmartRoom: единственная колонка «Физический адрес» выбирается в основном поле «Адрес», включая рекомендацию в окне проверки колонок.
- Если файл содержит отдельные колонки адреса и физического адреса, обе сохраняются раздельно.
- Проверены MAC, серийный номер, ID помещения, ID устройства, полный адрес локации, модель, производитель, IP и тип устройства; добавлены проверки переставленных колонок, JSON-переноса и режима без расширения Main.
- В Chrome проверено автоматическое сопоставление колонок, сохранение полного адреса и раздельных ID, а также исключение устройства только из SmartRoom при выключенном расширении.

Скачать всю программу: **MAC-Analyzer-Pro-Next-full.zip**. Внутри — автономный HTML, Windows-компонент, исходники, справочники и документация. Пользовательские базы не включены.

Проверки: 1 945 JavaScript-тестов, 199 Python-тестов, lint и синтаксис, общий и целевой Chrome smoke, запуск Windows-компонента, содержимое ZIP и SHA-256.

При сохранённом ранее ручном сопоставлении откройте проверку колонок и примените новый автовыбор либо выберите адрес вручную. Существующая история не переписывается автоматически.
