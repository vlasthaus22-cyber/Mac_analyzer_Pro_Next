# MAC Analyzer Pro Next v2.1.0-beta.1

Промежуточная загружаемая версия текущей реализации MAC Analyzer Pro Next.
Она включает доступные возможности программы и полный исходный пакет. Это
предварительная версия: полный parity с эталоном ещё не подтверждён.

## Что доступно

- локальный импорт Main, SmartRoom и DDIO с нормализацией и сопоставлением;
- объединение данных, Final, Inventory и History в IndexedDB текущего браузера;
- поиск, фильтрация, сортировка и постраничный просмотр;
- dashboard, сравнение Final и аналитика по помещениям, устройствам и MAC;
- portable HTML для запуска в браузере и автономный Windows host;
- экспорт и импорт portable database archive.

Данные импортируются и обрабатываются локально. IndexedDB хранится в профиле
браузера. Для переноса базы на другой компьютер используйте экспортируемый
portable archive и импортируйте его там.

## Состояние переноса

Реестр содержит 188 проверяемых требований. На дату сборки полностью закрыты
38 требований; 150 остаются открытыми или частичными: 115 требуют browser
smoke/E2E, 29 относятся к backend/REST, 6 — к внешним интеграциям. Поэтому
функции, не перечисленные среди доступных и не отмеченные в реестре как
проверенные, нельзя считать эквивалентными эталону.

## Проверка этой сборки

- 1 298 тестов Node.js и 48 Python integration tests пройдены;
- ESLint, синтаксические проверки, portable HTML/worker сборка и проверка
  packaged Windows host пройдены;
- ZIP прошёл проверку состава и контрольных сумм: 275 файлов;
- реальный browser smoke/E2E для этой сборки не выполнялся.

Архив содержит `dist/MAC-Analyzer-Pro-Next.html`, исходный код,
документацию, тесты, инструкции, reference data и при сборке на Windows
`dist/MAC-Analyzer-Pro-Next-Host.exe`. Не помещайте пользовательские базы,
пароли или импортированные сетевые данные в архив.
