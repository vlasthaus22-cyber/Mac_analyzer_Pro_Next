# PyInstaller

The optional Windows host is packaged with PyInstaller 6.22.3 and
`pyinstaller-hooks-contrib` 2026.8. PyInstaller is distributed under GPL-2.0
with a bootloader exception that permits distributing executables built from
independent application source under the application's chosen license. The
hooks project is Apache-2.0/GPL-2.0 dual-licensed. No PyInstaller Python source
is copied into this repository; the generated host executable is created by
the local packaging step.
