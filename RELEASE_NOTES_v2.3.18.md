# MAC Analyzer Pro Next v2.3.18

- В разделе «База, справочники и экспорт» появилось действие **«Архивировать и убрать из аналитики»**. После успешной записи архивные снимки скрываются в сравнении, графиках и хронологии. Новые снимки отображаются сразу.
- В разделе «Аналитика» кнопка **«Показать все локальные архивы»** подключает архивные снимки и их историю для просмотра. Данные читаются порциями, без восстановления в рабочую базу и дублирования снимков. Активный Final сохраняется.
- При создании локального архива проверка блоков снимков совмещена с копированием. Повторная сверка проверяет целостность на случай изменений базы во время записи.
- Потоковый JSON-экспорт реже обращается к диску, объединяя небольшие фрагменты. Неполные снимки выявляются до завершения экспорта.
- Обычные резервные архивы, экспорт и восстановление по-прежнему доступны. Автономный HTML работает по-прежнему локально в браузере.

Полный ZIP содержит автономный HTML, Windows-компонент, исходники и документацию. Для файлов сборки приложены SHA-256.
