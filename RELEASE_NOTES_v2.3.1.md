# MAC Analyzer Pro Next v2.3.1

Стабильное обновление с исправлениями отмены обработки, отображения адресных полей в поиске и отчётности автоопределения производителя/модели.

## Исправления

- Кнопка «Отменить» останавливает текущее обогащение безопасно: операция сообщает об отмене, не сохраняет неполный Final и не показывает отмену как ошибку.
- Общая отмена охватывает также поиск по сохранённым Final, запросы таблицы и локальную кластеризацию, когда они выполняются.
- В результатах поиска по сохранённым Final помещение, адрес и физический адрес показаны отдельно. Пустой физический адрес больше не маскируется значением помещения или адреса.
- Итог обогащения показывает, сколько производителей и моделей определено локально. Счётчики включают OUI, известные модели/MAC5, текстовое распознавание и однозначное совпадение с похожими устройствами.

Автоматическое определение модели использует локальные справочники, правила MAC5 и подтверждённые данные сохранённых Final. Если надёжного совпадения нет, поле остаётся пустым: программа не придумывает модель по одному лишь MAC.

## Проверки

- `pnpm check` и `pnpm check:release-readiness` прошли.
- Browser smoke проверил нажатие кнопки отмены во время активного объединения и отсутствие частичной записи Final.
- Полный ZIP, автономный HTML и Windows host собраны и проверены.

Выпуск включает автономный HTML, Windows host, полный ZIP исходников и SHA-256 sidecar-файлы.
