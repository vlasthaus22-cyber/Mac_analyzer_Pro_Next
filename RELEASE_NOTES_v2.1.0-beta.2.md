# MAC Analyzer Pro Next v2.1.0-beta.2

Промежуточная загружаемая beta-версия текущей реализации MAC Analyzer Pro Next. Включает portable HTML, Windows loopback host и полный исходный пакет. Это prerelease: полный parity с эталоном пока не подтверждён.

## Возможности

- Локальный импорт Main, SmartRoom и DDIO, нормализация, сопоставление и обогащение.
- Final, накопительный Inventory и History в IndexedDB текущего браузера.
- Поиск, фильтрация, сортировка, постраничные таблицы и виртуальный рендер.
- Сравнение снимков, dashboard, отчёты и аналитика по помещениям, устройствам и MAC.
- Импорт/экспорт переносимого архива; Windows host для копирования выбранных снимков и локальных REST-функций.

Все данные оборудования обрабатываются локально. IndexedDB привязана к профилю браузера; для переноса между устройствами используйте portable archive.

## Состояние parity

Реестр содержит 188 требований: полностью подтверждено 46 (24,5%); кодом и автотестами покрыто 185 (98,4%). Ещё 142 пункта остаются открытыми или частичными: 133 требуют browser smoke/E2E, 5 относятся к backend/REST, 2 к внешним интеграциям и 2 к ограничениям/расхождениям источников. Реальный browser smoke для этой сборки не выполнялся. Эта версия выпущена по прямому запросу пользователя как промежуточный prerelease; она не означает завершённый паритет.

## Проверки

Полный `pnpm check` завершился успешно: синтаксис, ESLint, проверка 188 строк матрицы, portable HTML и worker, Windows host runtime, сборка и проверка ZIP, Node unit/IndexedDB tests и 70 Python integration tests. Полная read-only проверка исходной SQLite-базы прошла: integrity=ok, пропущенных строк нет, все девять восстановленных коллекций совпали с целевыми counts; 8 повторных стабильных Inventory ID объединены.

## Установка и данные

Для браузера откройте автономный `MAC-Analyzer-Pro-Next.html`. Windows-пакет содержит `MAC-Analyzer-Pro-Next-Host.exe`; инструкция запуска находится в ZIP и README. Не помещайте пользовательские базы, секреты или импортированные данные в дистрибутив.
