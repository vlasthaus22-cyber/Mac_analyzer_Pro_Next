# MAC Analyzer Pro Next v2.3.13

- Исправлен запуск массового объединения после выбора файлов. «Запустить очередь» сам подготавливает пары, проверяет сопоставление и предлагает подтвердить запуск. Ошибки показываются рядом с кнопкой. Отмена не записывает снимки; повторный клик не создаёт вторую очередь.
- Обычные файлы и папки теперь выбираются отдельно. Ранее основной файловый диалог массового объединения был ограничен выбором папки.
- «Помещение» добавлено в основные поля SmartRoom рядом с адресом. Дополнительные поля Main и SmartRoom остаются доступными через «＋».
- Main, SmartRoom и DDIO расположены в трёх колонках — и при выборе источников, и при проверке сопоставления. Основные поля не требуют внутренней прокрутки. Проверена раскладка при ширине 1024 и 1600.
- Проверена точность двух последовательных циклов: заполнение помещения, полного адреса, модели и IP, сохранение состава Main без SmartRoom-only устройств.
- Проверено включение архивных снимков в аналитику: изменения из архивов учитываются, повторное восстановление не создаёт дубликатов, активный снимок сохраняется и его число устройств не суммируется с архивами.

Скачать всю программу: **MAC-Analyzer-Pro-Next-full.zip** — автономный HTML, Windows-компонент, исходники, справочники и документация. Пользовательские базы не включены.

Чтобы включить снимки, находящиеся только внутри локальных архивов, используйте в аналитике «Включить локальные архивы в аналитику». Инструкция: `docs/ANALYTICS_LOGIC.md`.
