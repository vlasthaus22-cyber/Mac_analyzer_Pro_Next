Документация

Как работает программа

1. Импорт

Программа читает CSV, TSV, JSON и XLSX локально. Файлы никуда не отправляются.

2. Идентификация

Приоритет: Device ID → serial → MAC. Слабые совпадения не объединяют устройства автоматически.

3. Обогащение

SmartRoom дополняет атрибуты. DDIO заполняет пустой IP по точному MAC. Previous Final восстанавливает только непротиворечивые пропуски.

4. Сохранение

Final становится активным только после успешной транзакции IndexedDB. Inventory и история сохраняются отдельно.

5. Аналитика

KPI, графики и изменения строятся по полным Final, а не по 50 строкам видимой страницы.

6. Перенос

Создайте архив в разделе «База и экспорт», затем импортируйте его в другом браузере или на другом компьютере.
