Профиль совместимости выбирает и порядок источников, и алгоритм похожих устройств: PyQt ищет по четырёхбайтовому префиксу, Web — по более точным MAC-префиксам; без приоритета история заполняет поля, оставшиеся пустыми после локального определения.

IP коммутатора → физический адрес

Точные ручные правила хранятся локально и входят в переносимый архив. При применении заполняются только пустые адреса активного Final; его ID и дата сохраняются.

Автозаполнение физического адреса

При объединении сопоставляет IP коммутатора с локальными правилами. Частичное совпадение IPv4 применяется, только если все правила подсети указывают на один адрес. Историческая подстановка использует только подтверждённые данные успешных Final.

Правила моделей по MAC

Точное совпадение по первым 3–5 байтам MAC. Префикс должен иметь 6, 8 или 10 шестнадцатеричных знаков.

Документация

Как работает программа

1. Отдельный анализ

Проверьте один файл, настройте колонки и выгрузите сводку CSV/JSON без изменения базы.

2. Импорт

Программа читает CSV, TSV, TXT, JSON, XLS, XLSX и XLSM локально. Legacy XLS ограничен размером 16 MiB. Файлы никуда не отправляются.

3. Идентификация

Сильные признаки идут по приоритету: сохранённый внутренний ID → Device ID → серийный номер → основной MAC → дополнительный MAC. Hostname помогает сопоставлению, но сам не разрешает неоднозначность; Smartroom ID и IP — слабые признаки.

4. Обогащение

SmartRoom дополняет атрибуты. DDIO заполняет пустой IP по точному MAC. Previous Final восстанавливает только непротиворечивые пропуски.

5. Сохранение

Final становится активным только после успешной транзакции IndexedDB. Inventory и история сохраняются отдельно.

6. Аналитика

KPI, графики и изменения строятся по полным Final, а не по 50 строкам видимой страницы.

7. Перенос

Создайте архив в разделе «База и экспорт», затем импортируйте его в другом браузере или на другом компьютере.

Где хранится база Next

Рабочая база хранится в IndexedDB текущего профиля Chrome или Edge и не является отдельным файлом. Не копируйте внутренние файлы профиля браузера: для резервной копии нажмите «Выгрузить архив Next». Браузер скачает файл вида mac-analyzer-next-ГГГГ-ММ-ДД.madb.json.

Куда сохранить и как загрузить архив

Сохраните скачанный .madb.json в выбранную папку резервных копий, на USB-диск или в защищённое хранилище. На другом компьютере откройте MAC Analyzer Pro Next, перейдите в «База, справочники и экспорт» → «Загрузить архив» и выберите этот файл. Импорт дополняет локальную базу; существующие записи не удаляются. Для синхронизации через выбранную папку укажите её в блоке «Папка данных»: там используется mac-analyzer-data.madb.

Импорт базы MAC Analyzer Pro Web

В Web-версии штатный файл SQLite — data\databases\mac_analyzer_web.db в папке проекта. Если задана MAC_ANALYZER_DATA_DIR, ищите его в <каталог>\databases\; если задана MAC_ANALYZER_DATABASE_PATH, используйте путь к файлу из этой переменной. Сначала остановите Web-сервер, затем сохраните копию базы вне папок проекта, dist и Git. Если рядом остался одноимённый файл -wal, выберите основной файл и WAL одновременно. Next проверит контрольные суммы и применит завершённые транзакции к временной копии; исходные файлы не изменяются. В Next выберите копию через инженерный режим → «База, справочники и экспорт» → «Импортировать SQLite». Поддерживаемые данные будут добавлены в IndexedDB текущего браузера; существующие записи не удаляются, а пропущенные таблицы будут перечислены в результате импорта. Для переноса из Next сохраните архив .madb.json в выбранную папку резервных копий или на USB-диск.

Импорт базы старой PyQt-версии

Сначала закройте старую программу. В типовой Windows-Portable поставке проверьте data\legacy\: там могут быть mac_history.db, vendor_model_history.db и mac_analyzer_stats.db. При заданной MAC_ANALYZER_DATA_DIR ищите их в <каталог>\legacy\. При самостоятельном запуске PyQt-скрипта файлы mac_history.db и vendor_model_history.db создаются относительно рабочей папки процесса; проверьте папку Start in ярлыка. Импортируйте нужные базы по одной: инженерный режим → «База, справочники и экспорт» → «Импортировать SQLite». Выбирайте исходный файл через диалог, не переименовывайте его и не копируйте в папку Next.

Самодиагностика

Проверка читает IndexedDB, чанки Final, индексы и доступную квоту. При запуске через loopback optional host эта же кнопка дополнительно читает структуру его локальных каталогов и SQLite в режиме read-only. Данные устройств не отправляются; база и каталоги не изменяются.
