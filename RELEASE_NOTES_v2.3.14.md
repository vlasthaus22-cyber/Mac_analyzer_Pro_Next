# MAC Analyzer Pro Next v2.3.14

- Дополнительные поля Main и SmartRoom выключены по умолчанию и не подбираются автоматически. Галочка разрешает ручное сопоставление. При снятии галочки назначения удаляются, колонки не используются при чтении источника.
- Старые планы массового объединения очищаются от выключенных дополнительных назначений перед проверкой. Ручной выбор занятой колонки переназначает её с уведомлением вместо сохранения дубликата.
- Исправлен обработчик выбора пользовательской колонки, который мог создавать лишнее назначение `undefined`.
- При конфликте основных полей сообщение показывает конкретную колонку и названия полей.
- Добавлена папка `database/` с инструкцией переноса JSON-базы. Импорт выполняется через «Загрузить базу из JSON»; рабочая база HTML остаётся в IndexedDB. Пользовательские файлы из этой папки не включаются в Git или релизный ZIP.

**Полная программа: MAC-Analyzer-Pro-Next-full.zip** — автономный HTML, Windows-компонент, исходники, справочники и документация. Пользовательская база не включена.

Проверены 1 951 JavaScript-тест, 199 Python-тестов, общий Chrome smoke и отдельный сценарий дополнительных полей: включение без автоподбора, ручное переназначение, отключение, успешная массовая очередь, отмена и защита от повторного запуска. Сборка Windows и полный ZIP проверяются с SHA-256.

После обновления заново сформируйте пары массового объединения. Для оставшихся конфликтов основных полей выберите разные колонки либо «Не использовать» по подсказке ошибки.
