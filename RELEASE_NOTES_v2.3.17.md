# MAC Analyzer Pro Next v2.3.17

- Main определяет состав Final в стандартном режиме. SmartRoom дополняет его по точному MAC, включая однозначное совпадение с дополнительным MAC из сопоставленного столбца. Противоречия адресов и помещений попадают в диагностику.
- Полный адрес SmartRoom имеет приоритет. Подстановка по точному IP коммутатора дополняет отдельный этаж при согласующихся данных. Исторический подбор требует подтверждения несколькими Final.
- Встроенный IEEE-справочник сохраняет источник определения производителя для MA-L, MA-M и MA-S. Проверены правила обучения производителя и модели и сохранение исходных значений.
- В аналитике доступны статусы, полный список «Без помещения», изменения по устройствам и хронология MAC. В хронологии помещений работает поиск по названию, адресу и SmartRoom ID. Совпадающие записи помещения без ID объединяются с единственным подтверждённым ID.
- Inventory показывает последнюю запись при поиске точного MAC и позволяет открыть остальные записи. При изменении колонок в массовой очереди выбранная пара остаётся раскрытой.
- Отчёт TXT уточняет область расчёта и показывает счётчики совпадений MAC и конфликтов местоположения.

Полный ZIP содержит автономный HTML, Windows-компонент, исходники, документацию и справочники. Пользовательские данные хранятся в профиле браузера.
