# MAC Analyzer Pro Next v2.3.3

Стабильный полный выпуск приложения: автономный HTML, Windows host, исходный код, документация, справочники, тесты и инструкции.

## Исправления

- Повторные внутренние ID исправляются детерминированно. Исходное значение сохраняется для диагностики; конфликт ID больше не прерывает сохранение Final.
- Отмена во время атомарного сохранения прерывает транзакцию. Предыдущий успешный Final остаётся активным.
- Результат анализа одного файла показывает весь список устройств страницами по 100 строк из сохранённого набора.

## Полный комплект

- `dist/MAC-Analyzer-Pro-Next.html` — автономное приложение.
- `dist/MAC-Analyzer-Pro-Next-Host.exe` — Windows host.
- `MAC-Analyzer-Pro-Next-full.zip` — полный проект: HTML, host, исходники, документы, справочники, тесты и инструкции.
- ZIP и приложения сопровождаются SHA-256 контрольными суммами.

Проверки: полный набор Node-тестов, ESLint, синтаксис, готовность parity, сборка и проверка автономного приложения, состав ZIP, CRC и SHA-256.
