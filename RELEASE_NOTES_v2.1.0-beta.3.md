# MAC Analyzer Pro Next v2.1.0-beta.3

Промежуточная загружаемая beta-версия текущей ветки `codex/full-parity-mirror`. Она содержит portable HTML, Windows loopback host и полный исходный пакет. Полный parity с эталоном не подтверждён.

## Возможности

- Локальный импорт Main, SmartRoom и DDIO, нормализация, сопоставление и обогащение.
- Final, накопительный Inventory и History в IndexedDB текущего браузера.
- Поиск, фильтрация, сортировка, постраничные таблицы и виртуальный рендер.
- Сравнение снимков, dashboard, отчёты и аналитика по помещениям, устройствам и MAC.
- Импорт/экспорт переносимого архива; Windows host для выбранных копий снимков и локальных REST-функций.
- Оптимизированные SQLite snapshot index/retry/page paths с миграциями и regression-проверками.

Все данные оборудования обрабатываются локально. IndexedDB привязана к профилю браузера; для переноса между устройствами используйте portable archive.

## Состояние parity

Реестр содержит 188 требований: полностью подтверждено 47 (25%); кодом и автотестами покрыто 185 (98,4%). Ещё 141 пункт остаётся открытым или частичным: 132 требуют browser smoke/E2E, 5 относятся к backend/REST, 2 к внешним интеграциям и 2 к ограничениям/расхождениям источников. Реальный browser smoke для этой сборки не выполнялся. Это промежуточный prerelease и не заявление о полном паритете.

## Проверки

`node scripts/check.mjs` завершился успешно: syntax, ESLint, реестр из 188 требований, portable HTML/worker, Windows host build/runtime, ZIP verifier, все Node unit/IndexedDB tests и 78 Python integration tests. ZIP содержит 315 файлов. Browser smoke/E2E не выполнялся из согласованного code-only режима. Release-readiness завершился ожидаемым отказом: 47/188 полностью подтверждено; 141 пункт остаётся открытым или частичным. Публичный prerelease выпускается по прямому запросу пользователя с явным раскрытием этих ограничений.

Для браузера откройте автономный `MAC-Analyzer-Pro-Next.html`. Windows-пакет содержит `MAC-Analyzer-Pro-Next-Host.exe`; инструкция запуска находится в ZIP и README. Не помещайте пользовательские базы, секреты или импортированные данные в дистрибутив.
