# MAC Analyzer Pro Next v2.3.2

Стабильный полный выпуск с исправлениями v2.3.1 и сжатым архивом проекта. Архив включает автономный HTML, Windows host, исходный код, документацию, справочники, тесты и инструкции.

## Исправления приложения

- Кнопка «Отменить» прерывает обогащение и поддерживаемые длительные действия. Отмена обрабатывается без ошибочного баннера и не сохраняет неполный Final.
- В поиске сохранённых Final помещение, адрес и физический адрес отображаются раздельно.
- Результаты обогащения показывают количество определённых производителей и моделей. Модель заполняется только при наличии однозначного локального или исторического подтверждения.

## Упаковка

- Полный ZIP сохраняет все 358 файлов и использует DEFLATE для сжимаемых данных; уже сжатые HTML и Windows host хранятся без повторного сжатия.
- SHA-256 контрольные суммы приложены отдельно и включены в ZIP.

## Проверки

- `pnpm check` и `pnpm check:release-readiness`.
- Browser smoke отмены обогащения и отображения отдельных адресных полей.
- Проверка состава полного ZIP, CRC и SHA-256 всех 358 файлов.
