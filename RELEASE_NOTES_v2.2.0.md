# MAC Analyzer Pro Next v2.2.0

Полный комплект текущей версии проекта: автономное HTML-приложение, optional Windows host, исходный код, справочные материалы и инструкции. Версия содержит проверенные изменения по управлению локальным OUI-справочником и снижению памяти временной аналитики помещений.

## Изменения

- Optional Windows host при запуске читает `data/reference/oui.csv` (предпочтительно) или `data/reference/oui.txt` и обновляет только справочные/builtin vendor mappings в собственной SQLite-базе. Поддержаны назначения 3–5 байт, SHA-256 идемпотентность; пользовательские и выученные правила сохраняются.
- Старые `oui.csv`/`oui.txt` в корневой папке данных безопасно перемещаются в `data/reference`. Существующий файл назначения не перезаписывается.
- Сборка host проверяет этот сценарий на упакованном Windows EXE в Unicode-пути, включая старт, штатную остановку и health endpoint.
- Комнатная временная аналитика Dashboard повторно использует компактный roster и не создаёт дополнительный массив указателей и клон каждого устройства.

## Проверки и ограничения

- `pnpm check` прошёл: JavaScript syntax/ESLint, 188 уникальных строк матрицы, автономный HTML и worker, Windows host build/runtime, полный Node/Python наборы и проверка полного ZIP.
- Матрица паритета: **173/188 (92,0%) полностью подтверждено**, автопроверками покрыты **188/188** требований. **15 требований остаются открытыми или частичными** (11 browser smoke/E2E, backend/REST и внешние интеграции). Эта сборка содержит текущую реализованную функциональность; полное поведенческое совпадение со всем исходным PyQt-приложением ещё не подтверждено.
- Browser checks в release notes не означают, что все оставшиеся UI сценарии подтверждены. Смотрите `PARITY_REGISTRY.md` и `docs/PARITY_AUDIT.md` для конкретного статуса.

## Использование

- Для быстрого старта откройте `MAC-Analyzer-Pro-Next.html` в актуальном Chromium-based браузере.
- Windows host необязателен; запускайте его только для локальных SQLite-копий, API и диагностики. Он не синхронизирует SQLite и IndexedDB автоматически.
- Перенос пользовательских данных между браузерными профилями выполняйте через portable database archive. Release ZIP не содержит пользовательские базы.

SHA-256 HTML, Windows host и полного ZIP указан в `SHA256SUMS.txt` рядом с архивом.
