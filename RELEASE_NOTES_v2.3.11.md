# MAC Analyzer Pro Next v2.3.11

- SmartRoom: девять основных полей на экране, дополнительные поля раскрываются через «＋». Добавлены точные варианты заголовков адреса помещения и ID помещения. Все стандартные поля доступны для ручного выбора.
- Массовое объединение: корректные пары можно подтвердить одной кнопкой; обязательная проверка идентификаторов и конфликтов колонок сохранена.
- По умолчанию при запуске выбран режим без расширения состава Main. Добавление устройств из SmartRoom требует явного выбора.
- Аналитика: назначение помещения определяется по названию комнаты или ID SmartRoom. Счётчик и список устройств без помещения согласованы; старые расчётные кэши пересчитываются.
- Над аналитикой показаны источник расчёта и наличие фильтров. Хронология стала компактнее; повторное появление MAC имеет отдельную подпись и сохраняет предыдущее состояние устройства для сравнения.
- Проверка на 12 000 MAC Main и 15 000 строк SmartRoom подтверждает 12 000 устройств результата и 2 000 без помещения в режиме без расширения.

Полный комплект — `MAC-Analyzer-Pro-Next-full.zip`: автономный HTML, Windows-компонент, исходники, справочники и документация. Пользовательские базы не включены.

Подробная логика и инструкция: `docs/ANALYTICS_LOGIC.md`.
