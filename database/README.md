# Папка переноса базы

Сюда можно сохранять скачанные из программы резервные базы `.madb.json`.
Рабочая база HTML находится в IndexedDB браузера, а не в этой папке.

1. В программе откройте «База, справочники и экспорт».
2. Нажмите «Скачать базу в JSON (.madb.json)» и сохраните файл сюда.
3. Для загрузки нажмите «Загрузить базу из JSON» и выберите нужный файл.

Просто копирование файла в папку не запускает импорт. Браузер получает доступ
к файлам только после вашего выбора. Для автоматического резервного копирования
используйте имеющуюся в программе настройку папки данных с явным разрешением.
Optional host отдельно использует `data/imports` для входящих файлов и
`data/backups` для резервных копий; это не рабочая IndexedDB HTML.

Пользовательские JSON не включаются в Git и релизные ZIP.
