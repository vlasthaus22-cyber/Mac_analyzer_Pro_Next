# Changelog

## Проверка parity — 2026-10-20

- Захватный обработчик ограничения доступа вынесен в общий UI guard; регрессии проверяют, что крестик сообщения об ошибке отрабатывает внутри закрытого инженерного представления, а соседние ограниченные действия по-прежнему блокируются.
- Проверка portable-сборки теперь подтверждает, что автономный HTML включает тот же доступный для пользователя путь закрытия баннера, обход capture-phase ограничения и сохранённую блокировку остальных инженерных действий.
- Одновременная потоковая запись XLSX в одну выбранную папку и под одним именем сериализуется локально и через Browser Locks между вкладками; повторная запись получает ошибку существующего файла, а не перезаписывает его.
- Если Browser Locks API недоступен для конкретного origin, запись использует локальную блокировку; сбой начавшейся файловой операции не запускается повторно.
- Потоковая перезапись общего portable `.madb`-архива тоже проходит под межвкладочным lock: отложенный exporter начинает читать IndexedDB после получения lock, и две вкладки не открывают writer одновременно.

## Предрелизная проверка parity — 2026-10-20

- Матрица сверена с Web-эталоном MAC Analyzer Pro 1.0.82: все 178/178 source IDs покрыты, 10 дополнительных строк описывают требования Next. Зафиксирован точный Web parity index и SHA-256; регрессии проверяют список ID и формулировки исходных пунктов.

- Каждая из 27 распознаваемых SQLite-таблиц теперь имеет явную проверку обязательных колонок; source regression сверяет требования с колонками всех восьми `CREATE TABLE` из неизменённого PyQt-файла. `mac_movements` требует `mac`, `field_name` и время в `timestamp` или legacy `changed_at`; несовместимые схемы получают диагностику, а импорт продолжает совместимые таблицы.

- SQLite `resolved_device_inventory.payload_json` больше не теряет confidence/source производителя и модели при импорте в IndexedDB Inventory. Camel/snake aliases нормализуются, confidence ограничен 0–1; unit и disposable IndexedDB regressions проверяют оба поля и оба источника.

- Импорт MAC-полей повторяет PyQt `MACValidator.normalize`: удаляет все не-HEX символы и дополняет 8/10/11-значные записи, сохраняя нормализованные all-zero/broadcast значения в данных. Строгая нормализация сильной идентичности по-прежнему отвергает эти placeholders, поэтому они не могут объединять устройства. Также поддержаны формы с пробелами между шестью байтами и тремя 4-символьными HEX-группами.

- Единая схема сравнения двух файлов включает «Время аутентификации устройства» в CSV и XLSX; добавлены регрессии на колонку и значение.

- Время аутентификации добавлено в стандартные видимые колонки Inventory и обычный XLSX Inventory; раньше поле было только в каталоге включаемых колонок и отсутствовало в экспорте по умолчанию.

- В менеджер колонок Inventory добавлено поле «Источник»: оно показывает source/provenance устройства или список его источников и может быть включено в таблицу и экспорт.

- Миграция старых настроек колонок сохраняет общий столбец `oui`, преобразуя его в OUI-3 байта по умолчанию, как в исходном Web-приложении; явные настройки OUI-4/5/6 остаются без изменений.

- XLSX-сводка аналитики сохраняет source-compatible top 50 моделей при полном подсчёте и чтении рейтинга через курсорные страницы; регрессия различает полный итог в 52 модели и 50 строк листа.

- Аудит portable-переноса классифицировал все 24 IndexedDB stores: обычные и специальные portable коллекции, отдельный экспорт именованных архивов, origin-bound file handles и перестраиваемые кэши. Disposable schema regression не позволит добавить хранилище без явной transfer-политики.

- Компактный Previous Final больше не теряет confidence и provenance производителя/модели при потоковом восстановлении: сохранены `vendorConfidence`, `vendorSource`, `modelConfidence`, `modelSource` и `fieldSources`; disposable IndexedDB regression проверяет перенос этих значений через enrichment.

- Добавлен отдельный локальный каталог IEEE CID с поиском по шестнадцатеричному Assignment и названию организации, точной пагинацией и безопасным выводом. CID явно исключён из MAC vendor lookup; данные берутся только из проверенного bundled registry.
- Исправлен потоковый импорт portable `.madb`: теперь он восстанавливает `legacyObservations` и `dataQualityReports`, которые экспортировались, но пропускались reader-ом. Экспортёр и импортёр используют общий manifest коллекций; добавлены manifest, reader и сквозные disposable IndexedDB regressions.

- Portable artifact checker теперь отклоняет сборку без recovery для ошибки, уже показанной до открытия modal dialog: проверяет встроенный `MutationObserver` и возврат баннера после закрытия диалога. Это предотвращает повторное распространение старого HTML, в котором крестик оказывался недоступен за backdrop.
- Portable `.madb` теперь сохраняет большие файлы локальной очереди расписаний из `fileHandles`: экспортирует и импортирует их порциями по 192 КиБ и атомарно связывает восстановленный Blob с записью очереди. Добавлен round-trip тест файла больше 30 МиБ.
- Portable `.madb` включает файлы очереди, содержимое которых удерживается импортированной SQLite-базой: экспорт по ID расписания находит исходную базу, читает Base64 частями и переносит вложение; без доступного reader экспорт явно завершается ошибкой. Добавлена disposable IndexedDB регрессия на перенос и отказ без reader.
- Добавлена сквозная регрессия атомарного отказа потокового архива: после staging корректного Inventory следующий некорректный History отклоняет импорт; прежние данные остаются, временные archive-записи удаляются.
- Восстановление legacy workspace больше не преобразует пробельные/hex-строки индексов колонок в индекс 0; принимает только целые числа и строки из десятичных цифр.
- После назначения роли дополнительному источнику селектор сразу обновляется, отражая сохранённую роль.
- Именованные локальные архивы захватывают бинарные вложения очереди вместе с остальными записями и выгружают только сохранённые чанки. Регрессия меняет live-запись и Blob после создания архива и проверяет сохранение первоначального состояния при экспорте/импорте.
- Восстановление именованного архива проверяет наличие Blob по сохранённой локальной ссылке; если файл был удалён, stale-ссылка больше не пропускает его восстановление.
- Совместимый object API `Database.importArchive()` также проверяет task/file association и границы чанков, восстанавливает файл вместе с записью очереди и не перезаписывает чужой локальный Blob; тесты покрывают round-trip и отказ до записи на несовпадающем task ID.
- Двойной клик в Inventory следует действиям PyQt: для MAC предлагает открыть хронологию или аналитику устройства, для модели без MAC показывает префиксы. Добавлены проверки выбора цели и привязки UI; browser smoke остаётся открытым.
