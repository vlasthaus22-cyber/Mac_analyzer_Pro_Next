# Changelog

## 2.0.0 — 2026-10-14

- Полностью новая browser-first архитектура без старого монолитного контроллера.
- Единая идентификация по Device ID, serial, MAC и дополнительному MAC.
- Два однозначных режима `NO_EXPANSION` и `ALLOW_EXPANSION`.
- Независимая подстановка IP из DDIO по точному MAC.
- Атомарные порционные Final-снимки, Inventory и History в IndexedDB.
- Поиск по всему накопительному Inventory с сортировкой и пагинацией.
- Final-to-Final аналитика, недельная динамика и churn MAC.
- Полная карточка переговорной при разных IP коммутатора.
- Корректная работа помещений без Smartroom ID через однозначный составной ключ.
- Хронология MAC и помещения по всем Final.
- Массовая очередь Main/SmartRoom/DDIO по ближайшим датам.
- CSV/TSV/JSON/XLSX импорт и CSV/JSON/архивный экспорт.
- Встроенная IEEE OUI-база и накопительное изучение моделей.
- Автономная сборка в один HTML-файл.
