# MAC Analyzer Pro Next v2.1.0 — кандидат на релиз

Сборка и полный комплект проверены локально. GitHub Release пока не опубликован: release gate из `AGENTS.md` требует закрыть все обязательные пункты паритета и runtime-проверки.

## Что входит

- Автономное HTML-приложение с локальным импортом Main, SmartRoom и DDIO, объединением, сравнениями и массовой очередью.
- Final, Inventory и History на IndexedDB, Dashboard, поиск, аналитика и отчёты.
- Переносимые архивы и явное восстановление; optional Windows loopback host для SQLite-копий, диагностики и локальных API.
- Локальные справочники и правила vendor/model; внешнее enrichment и уведомления выключены по умолчанию и требуют явного opt-in.
- Диагностика, резервное копирование/восстановление, SQLite maintenance для выбранной копии и исправления импорта и работы с большими данными.
