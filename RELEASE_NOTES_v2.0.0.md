# MAC Analyzer Pro Next v2.0.0

Первый релиз полностью переписанной программы.

## Основные возможности

- Main + SmartRoom + DDIO с проверяемым сопоставлением колонок;
- два режима количества устройств;
- DDIO-IP по точному MAC независимо от IP коммутатора;
- OUI и известные модели;
- Final, Inventory, History и переносимая база;
- поиск, сортировка, пагинация;
- dashboard и Final-to-Final аналитика;
- полная информация о переговорных с разными IP коммутатора;
- хронология MAC и помещений;
- массовое обогащение папок;
- единый автономный `MAC-Analyzer-Pro-Next.html`.

## Проверка

- 21 автоматический тест;
- ESLint без ошибок;
- 10 000 уникальных Main-устройств обогащаются примерно за 0,25 секунды в
  тестовой среде;
- реальный Edge smoke-тест: Main + SmartRoom + DDIO → Final → IndexedDB →
  Inventory → DDIO-IP → аналитика переговорной.
